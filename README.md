## 🚀 Featured Projects  

### 🔹 [AutoNetScan](https://github.com/cool5102/AutoNetScan)  
A multi-threaded Python tool that scans local or remote networks for active hosts and open ports.  
Includes **auto IP detection**, **manual entry option**, **GUI prompt**, and **CSV reporting**.  

### 🔹 [LogGuard](https://github.com/cool5102/LogGuard)  
Python-based security automation tool that detects brute-force login attempts from system logs.  
The **AutoBan Edition** can automatically block suspicious IPs using `ufw`, `iptables`, or `netsh`.  

### 🔹 [AutoRecon](https://github.com/cool5102/AutoRecon)  
Automated reconnaissance tool for domains and IPs using **WHOIS**, **DIG**, and optional **Nmap** scans.  
Generates clean, structured reports for penetration testing and audits.  

### 🔹 [PortMonitor](https://github.com/cool5102/PortMonitor)  
Monitors network ports in real time using **Nmap** and notifies users about new or closed ports — ideal for security audits and system monitoring.
